# MXH Route 1.14.2-mxh.1

本版将 MXH Route 的内核、桌面端与 Dashboard 同步至官方 sing-box 1.14.2 基线，同时保留独立安装、配置驱动的入口故障切换和原有私有更新通道。

- Windows 系统代理的实际开关与本地 CONNECT 健康分开判断。若开关被关闭但 HTTP/HTTPS 地址仍属于 MXH Route，连续确认两次后自动重新应用一次；再次被关闭则停止争夺并发出通知。其他代理地址、PAC、自动检测配置不会被抢占。
- 入口故障切换继续优先处理单节点故障；全部入口新近确认不可达且整体链路连续失败时，允许一次受控的整体重载，避免两套守护互相让位。
- 修正定制版更新界面：不显示实际不会生效的更新轨道选择。手动首选、故障切换顺序及已有设置保持不变。

已通过桌面端、Dashboard、关键内核包和安装器预检的自动测试，并完成 Windows x64 签名安装包构建。未在用户运行环境注入真实断网故障；安装更新前，当前运行的旧版本不会获得上述修复。

安装包使用既有 MXH Route 自签名证书。Windows 可能提示签名根证书不受信任；请核对本 Release 提供的 SHA-256 校验文件。此次发布不修改代理配置、节点顺序或服务器。
