# MXH Route 1.14.0-mxh.10

- 自动故障切换入口列表从当前代理配置动态读取，只显示成员全部为实际代理节点的非空 selector 分组。
- 排除引用其他组、包含直连、阻断、DNS、自动测速或缺失成员的业务、汇总和混合分组；不依赖组名或 Entry 后缀。
- 界面、保存校验、运行时探针及缓存恢复共用结构筛选规则。
- 移除写死的初始组名，首次使用需明确选择入口组；已有选择及排序不会被覆盖。
- 已保存组不再符合条件时，界面提示重新选择，运行时不为其创建探针，也不自动改选其他组。

当前配置仍需遵循业务组引用代理组的分层设计；应用按成员结构识别，不猜测组名的业务含义。保存后需主动重载代理，或在下次正常启动时生效。
