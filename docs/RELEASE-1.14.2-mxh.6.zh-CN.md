# MXH Route 1.14.2-mxh.6

整合延迟检测、配置导入和本地端口设置改进，继续基于 sing-box 1.14.2。

- 手动节点/分组测速的默认目标对齐 Clash Verge：使用 Cloudflare HTTP 测试地址，保留预热后请求计时及完整入口、落地链路。显式指定的测速目标不变，后台健康探测不变；不是把旧延迟除以二，也不是单程网络时延。更新后请重新测速，旧样本不会自动改写。
- “从文件导入”记住上次选择的文件夹。取消选择不改变记录；目录已不可用时回退到系统默认位置。
- 新增“设置 → 端口设置”，沿用应用原有设置列表、字体、输入框和开关。可调整混合代理端口，按需启用独立 SOCKS、HTTP 端口。
- 端口保存在当前配置，保存前检查范围、重复、其他入站和 TCP 端口占用。运行时明确显示“保存并重载”，失败尝试恢复原配置与服务；停止时仅保存，下次启动生效。
- 端口变更同步用于 Windows 系统代理和本地健康检测，保留手动选择的故障切换首选入口。重载串行执行，并在处理期间暂停本地守护观察，避免与自动恢复或手动停止相互干扰。

端口设置不是隐藏的全局覆盖：重新导入或更新远程配置后，读取新配置中的原生端口。已有监听地址、认证和标签保留；新建代理入站仅监听本机回环地址。高级配置含多个同类型代理入站时，请在配置编辑器中分别调整。

完成相关回归测试、桌面端构建、隔离界面预览和本机真实内核入站验证。发布不自动安装，不修改正在运行的代理或权威节点配置。

安装包沿用既有 MXH Route 自签名证书，Windows 可能提示根证书不受信任。请核对随 Release 提供的 SHA-256 校验文件。
