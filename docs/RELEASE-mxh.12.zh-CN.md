# MXH Route 1.14.0-mxh.12

- 自动切换和重载共用恢复操作代数，切换请求发出前立即作废旧重载证据，不依赖状态订阅及时更新。
- 切换或重载结束后进入 30 秒观察期，自动重载只能使用观察期后开始的新采样；入口监测启用时还需新的独立可达证据。
- 切换清空旧探针结果和重载计数，执行重载前再次核对恢复代数、分组选择及独立证据时效。
- 请求失败或超时也进入观察期，防止结果不确定时紧接着重载。观察期不阻止备用节点继续故障切换。
- 慢但成功不触发重载判断；节点恢复让位期间不累积旧重载次数。
- 补充只读 Windows 代理状态日志，不强制修改系统代理，不记录 PAC 地址或其他代理地址。

本次包含 Clash 对照审计后的恢复判断修订。未宣称历史 TLS 重置根因已经确定。应用需保持运行（可留在托盘）；更新安装后的正常启动会使用新机制。
