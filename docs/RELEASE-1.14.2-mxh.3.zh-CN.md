# MXH Route 1.14.2-mxh.3

本版继续使用 sing-box 1.14.2，优化系统代理状态和自动故障切换界面，不改变已有代理开关、节点顺序或恢复策略。

- 流量接管卡片保留整行宽度，增加留白，将系统代理状态放在下方独立区域；点击状态查看详细说明。暂停恢复时保留受保护的手动恢复入口，其他代理接管或状态未知时不提供强制抢占操作。
- 概述页新增“自动故障切换”摘要卡片，显示运行状态、当前节点、入口组及待应用提示；点击直接进入详情设置。支持在仪表项目中排序或隐藏，设置页入口继续保留。
- 故障切换详情采用应用现有字体、配色和设置分组样式。重复节点名称合并显示，规则、高级参数和配置路径默认折叠。
- 节点顺序支持手柄拖拽、浮动反馈和落点提示，也可用键盘上下方向键或按钮调整。排序仅修改草稿，保存与重载仍分开，重载前仍需确认。
- 界面说明同步当前机制：当前节点独立探测、首次失败快速复核、跳过当前节点选择健康备用、手动首选稳定恢复后切回。未保存或待应用的开关不冒充正在运行的监测状态。

前端 66 项测试、类型检查及生产构建通过；使用模拟配置验证拖拽、键盘排序、保存待应用、重载确认、系统代理详情、深浅色和窄窗口布局。未在用户当前代理上注入网络故障或执行重载。

安装包使用既有 MXH Route 自签名证书，Windows 可能提示根证书不受信任。请核对随 Release 提供的 SHA-256 校验文件。发布不会自动安装或改变当前代理状态。
