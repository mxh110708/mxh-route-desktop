# MXH Route 1.14.0-mxh.13

- 当前入口节点第一次探测失败后，约 1 秒后开始下一轮连续复核，不再每轮固定等待常规异常间隔。
- 仍需达到设定的连续失败轮数，并确认备用节点连续可用后才切换；一次失败不会直接切换。
- 当前节点恢复即重置失败计数；达到失败轮数但没有可用备用时，退回常规探测间隔，避免一直高频探测。
- 更新自动故障切换界面和中文文档，明确“常规异常轮间等待”不用于这段连续复核。

Windows x64 签名安装包；可通过应用内“检查更新”升级。此次变更只涉及客户端探测调度，不更改节点顺序或服务器配置。手动选择节点仍会暂停自动切换，重新启动或重载代理后恢复。
