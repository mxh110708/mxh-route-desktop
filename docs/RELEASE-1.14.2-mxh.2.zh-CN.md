# MXH Route 1.14.2-mxh.2

本版基于官方 sing-box 1.14.2，修复 Windows 系统代理恢复延迟、恢复额度重置过宽，以及慢备用节点拖延故障确认的问题。

- 系统代理状态独立检查：正常约 2 秒，发现匹配本应用的开关被关闭后约 1 秒复核，不再等待 HTTPS 探测或节点切换观察窗。仅恢复仍归属 MXH Route 的设置；其他代理地址、PAC 和自动检测配置继续避让。
- 自动恢复额度及不确定状态持久保存；切换分组、自动重载或单纯重启应用不会重置。重复关闭会暂停并提示，避免与其他代理软件反复争夺。用户明确重启代理才重新授权；受限的手动恢复入口也不会覆盖其他代理。
- 恢复 RPC 增加截止时间，核心在 Windows 设置锁内检查请求取消；结果不明时不自动重试。用户点停止时，排队中的旧恢复请求立即作废。
- 概述页新增 Windows 实际系统代理状态摘要，区分已开启、复核、恢复、避让、暂停和未知。沿用现有字号和组件风格。
- 当前入口与备用巡检分开调度，失败后连续复核不再等待全部候选；备用巡检最多两路并行，切换目标另行即时复核。迟到旧结果不能覆盖新结果，未采样的节点不累计失败。
- 保留配置驱动的节点顺序、手动首选、故障切换、稳定恢复后切回和显式排除当前入口。整体重载仍只是最后手段；不改变用户已有配置与自动切换开关。

已通过桌面端 78 项测试、Dashboard 56 项测试、TypeScript 检查、界面静态检查、关键 Go 包测试和 Windows 生产构建。实际 Windows 用户会话下的 Clash 启停故障注入仍需安装后验收；2–5 秒是正常调度条件下的本地开关恢复目标，不是所有网络故障的恢复保证。

安装包使用既有 MXH Route 自签名证书，Windows 可能提示根证书不受信任。请核对随 Release 提供的 SHA-256 校验文件。发布不会自动安装或改变当前代理状态。
