# MXH Route 1.14.0-mxh.7

## 配置驱动的故障切换

- 移除硬编码服务商名称和排序。默认按目标 selector 的节点列表顺序选择首选及备用，支持任意服务商名称。
- 新增应用数据目录中的 `priority-failover.json`，可配置启停、分组、显式节点顺序、失败／恢复轮数、稳定时间、冷却时间、探测超时及轮间等待。
- `order: []` 跟随组内顺序；非空列表仅使用列出的精确节点 tag。修改配置并重新关开代理或重载配置即可生效，无需再次发布安装包。
- 配置与旧运行缓存不匹配时不复用旧探测入口；自动重载只在策略与节点列表一致时保留原状态。
- 保留 mxh.6 的日志滚动保存、独立 HTTPS 探测、防抖和手动选择暂停规则。全部失败仍不会转 DIRECT。

## 验证与边界

新增任意分组／节点名称、跨服务商重排、显式顺序、配置关闭、参数校验、阈值变化和首次配置创建／保留测试。系统代理和 TUN 的现有权威配置均通过核心配置检查。

需覆盖安装并重新开一次代理。此次提供安装包，不自动安装或重启当前代理；尚未进行新版本已安装 GUI 的长时间实际故障切换验收。

配置位置、示例及限制见 [配置驱动故障切换说明](PRIORITY-FAILOVER.zh-CN.md)。当前支持一个受监测 selector；嵌套分组及 DIRECT 不作为自动候选。
